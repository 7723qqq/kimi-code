Make the dialogs and panels mouse-interactive in fullscreen mode. In fullscreen the app captures the mouse, so a panel that ignores mouse events cannot be clicked at all. The model picker (including its provider tabs and thinking-effort segments), the session list, the provider manager, the undo selector, the experiments panel, the goal queue, the settings pickers, the permission and workspace-trust prompts, the task browser, the plugins panel, and the question dialog now highlight the row under the pointer, turn pages with the wheel, and pick a row on click. In the question dialog a click picks an option, opens the free-text "Other" editor, switches tabs, and runs Submit/Cancel; in the plugins panel a click only selects a row, so destructive actions stay on the keyboard. Form panels accept the pointer too: clicking an input line puts the caret where you clicked (API key, feedback, custom registry, provider form), the Astron and Coding Plan settings select the field you click, the provider form selects the model row and the Save line under the pointer without submitting, and the help panel scrolls its own body with the wheel. Fullscreen mode is enabled with `tui_mode = "fullscreen"` in `tui.toml`.
