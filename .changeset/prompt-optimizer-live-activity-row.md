The Ctrl+P prompt rewrite now shows what it is doing in a live row above the input box: which stage it is in, and which file or pattern it is looking at when it reads or searches. Press Ctrl+P and the row appears immediately, updates as the rewrite reads files or thinks, and disappears as soon as the rewrite finishes or is cancelled.
