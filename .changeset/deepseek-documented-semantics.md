DeepSeek adaptation and reasoning follow the vendor's documented requirements, and silent losses become visible.

- `thinking`: a request that carries `tools` now replays the full prior reasoning. DeepSeek documents that `reasoning_content` "must be fully passed back to the API in all subsequent requests" when `tools` is present, and that omitting it returns HTTP 400. The requirement was previously modelled as a provider-trait capability (`preserveThinking`), which no DeepSeek trait populates, so nothing enforced it. It now lives on the model-family entry as `thinkingHistory.fullEchoWithTools`, is evaluated from the request's own tool list, and covers think parts that would otherwise be dropped.
- `sampling`: parameters DeepSeek documents as silently ignored while thinking is on (`temperature`, `presence_penalty`, `frequency_penalty`) are dropped from the outgoing request instead of being sent as no-ops. `top_p` is kept — the same page states it takes effect (clamped to 0.95–1.0). The filter runs after `extraParams` merges, since that is the path sampling options travel; applied earlier it would have been undone. Only names the family declares are touched.
- `adaptation`: the curated-versus-measured decision was made explicit in one place, used by both the system-prompt path and the reminder injection so the two could not disagree about which file a model receives. Families whose prompt shape is `minimal` skip the system-prompt path entirely, because their template has no `${model_adaptation_section}` placeholder. (The measured kind has since been removed; see the companion changeset.)
- `adaptation`: an oversized adaptation file is truncated at a `##` section boundary and reported, instead of being discarded whole. Guidance files are hand-written and sectioned, so a long final paragraph used to cost the entire adaptation without the model or the user seeing anything.
- `adaptation`: the reminder provider caches the in-flight load rather than the settled value, so concurrent steps read the file once; a resolved "no adaptation" is cached too, instead of re-listing the directory on every step. The load also no longer re-derives text from the conversation each step — the wire name and the file are both fixed within a session.
- `prompt`: `SystemPromptRenderResult` reports `droppedVars`, the supplied variables the active template never referenced. `renderPrompt` substitutes what it can and leaves the rest alone, so the minimal DeepSeek prompt was discarding AGENTS.md content, skill listings, plugin sections and more without a trace. Callers now log the list. Relatedly, AGENTS.md paths are seeded as "already injected" only when their content actually reached the prompt; under the minimal shape the body never arrives, and seeding it suppressed the reminder that points the model at the file.
- `attention`: the curated DeepSeek guidance is rewritten as positive directives, matching the negation weakness the family's notes attribute to it, and gains a worked example of carrying a task through. A primacy/recency claim that had been asserted without support now cites Lost in the Middle (arXiv:2307.03172), with the cache-prefix trade-off stated.
- `docs`: `human/llm/AGENTS.md` points at `docs/en/llm.md`, which did not exist; the guide is now written.
