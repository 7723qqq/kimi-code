Tool results, background-task metadata and stopped-subagent output now share one module for the "this output was truncated, the full copy is at this path, read it this way" block instead of four hand-written copies. It models the three shapes the block actually takes: an appended pointer (three lines, no size field, closing bracket on the hint), a replaced pointer (headline, caller lines, char size, optional byte size, path, hint) and an unpersisted pointer (no path and no hint, because there is nowhere to read from). The `output_size_*` line and the `next_step:` hint are single functions, so a stopped subagent's summary now carries `output_size_bytes` beside its path where it used to carry the path alone, and a foreground command that spills its log names its size with the wording the spill pointer already used. The appended and replaced shapes render byte-for-byte what they rendered before. Only the text a tool hands back changed; no tool name, description or parameter schema moved, so `toolsHash` is unchanged. The first turn after upgrading misses the prompt-cache prefix once, because tool output is part of the context.
