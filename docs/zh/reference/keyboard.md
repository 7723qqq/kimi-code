# 键盘快捷键

Kimi Code CLI 的 TUI 交互模式支持一套键盘快捷键。键位按使用场景分为七组：通用输入、模式切换、输入与编辑、流式输出期间、工具输出控制、审批面板，以及弹窗浏览。在 TUI 中输入 `/help` 可随时打开内置快捷键清单。

## 通用快捷键

以下键位在输入框中始终可用：

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 提交当前输入 |
| `Shift-Enter` / `Ctrl-J` | 在输入中插入换行 |
| `↑` / `↓` | 浏览输入历史 |
| `Esc` | 关闭弹窗 / 取消补全 / 中断流式输出或上下文压缩 |
| `Ctrl-C` | 中断当前流式输出，或清空输入框 |
| `Ctrl-D` | 在输入框为空时退出 Kimi Code CLI |
| `Ctrl-T` | 展开或折叠待办列表或待处理的审批提示（仅当折叠确实会显示或隐藏内容时生效） |
| `Ctrl-P` | 用 AI 重写输入框中的提示词 |
| `Ctrl-N` | 聚焦或释放实验性 `Updates` 面板 |

`Updates` 面板聚焦后：`←` / `→` 切换 agent 频道，`↑` / `↓` 滚动当前更新，`[` / `]` 在该频道的更新之间切换（`PgUp` / `PgDn` 同样可以切换；全屏模式下这两个键用于翻动会话记录），`Esc` 释放焦点。输入框上方的整条提示栏——待办列表、更新与待处理的审批——共用一个外框，并分为左右两半：右半固定为更新区，左半放待办列表与待处理的审批。更新区的表头行会显示当前页码与还有多少行未展示。整条提示栏不超过终端高度的一半（最多 20 行），更新区与其他面板共享这份高度预算。已结束的 agent 会折叠为一个 `+N done` 标签；当前查看的 agent 始终保留自己的标签，被折叠的内容仍可用 `←` / `→` 访问。每条新更新都从**顶部**开始显示，之后由更新区自行逐行向下读完，因此长更新按书写顺序阅读；读到底部即停止，手动滚动则立即接管。也支持鼠标，且不会抢占键盘：在更新区上滚轮滚动当前更新（不再穿透给会话记录，也不会抢占焦点——抢焦点仍是 `Ctrl-N` 的行为），并且**无需先点击一次即可生效**。点击频道标签切换该 agent；点击 `+N done` 展开被折叠的 agent，此时标签变为 `−N done`，同一点击即可折回。点击更新区其他任意位置会折叠或展开整个面板，与会话记录里点击折叠卡片的行为一致，同样不会抢占键盘。向上滚动后视图不再跟随新更新，滚回底部恢复跟随。

**流式输出期间**按 `Ctrl-C` 会立即取消，无需二次确认。

**退出程序**（输入框为空时按 `Ctrl-C`，或按 `Ctrl-D`）使用「双击确认」机制：第一次按下后状态栏会出现提示，再按一次相同的键才真正退出。中途按其他键会清除确认状态。

## 模式切换

| 快捷键 | 功能 |
| --- | --- |
| `Shift-Tab` | 循环切换审阅模式（Plan → Spec → 关闭） |
| `!` | 在空输入框中进入 Shell 模式 |

按 `Shift-Tab` 可在审阅模式之间循环：先进入 Plan，再切到 Spec，再关闭。Plan 模式下，Agent 会优先使用只读工具进行研究和规划，并可写入当前计划文件；`Bash` 按当前权限模式和普通规则处理，不会因 Plan 模式额外发起独立审批。单纯切换模式不会创建空计划文件。完整的模式关系见[斜杠命令](./slash-commands.md#模式与运行控制)。

在空输入框中键入 `!` 进入 Shell 模式，可直接运行终端命令；命令运行期间按 `Ctrl+B` 可将其转为后台任务。详见[交互与输入](../guides/interaction.md#shell-模式)。

## 输入与编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl-G` | 在外部编辑器中编辑当前输入 |
| `Ctrl-V` | 粘贴剪贴板中的图片或视频（Unix / macOS） |
| `Alt-V` | 粘贴剪贴板中的图片或视频（Windows） |
| `Ctrl--` | 撤销（Undo） |
| `Esc` `Esc` | 双击打开撤销选择框（空闲状态下） |

按 `Ctrl-G` 会打开外部编辑器，编辑器按以下优先级选择：

1. `/editor` 命令配置的编辑器
2. `$VISUAL` 环境变量
3. `$EDITOR` 环境变量

保存并退出后，编辑内容替换输入框；不保存退出则保持原样。

粘贴图片或视频时，输入框中显示占位符，实际媒体数据在提交时一并发送给模型。优先从系统剪贴板读取；Linux 上会尝试 Wayland 与 X11，WSL 下还会通过 PowerShell 兜底读取 Windows 剪贴板。

## 流式输出期间

流式输出（streaming）期间，输入框依然可以接收输入，并支持以下额外操作：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl-S` | Steer：将当前输入立即注入正在运行的轮次 |
| `Esc` | 中断当前流式输出 |
| `Ctrl-C` | 中断当前流式输出 |

按 `Ctrl-S` 时，模型会在下一个可中断的时机立刻看到你的消息，无需等待当前轮次结束。

## 工具输出

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl-O` | 展开或折叠工具输出、Shell 命令输出和压缩摘要 |

历史中存在折叠的工具调用结果或 Shell 命令输出时，按 `Ctrl-O` 可在折叠和展开之间切换。压缩完成后，同一个快捷键也会在压缩块中显示或隐藏压缩摘要。

## 审批面板

当 Agent 发起需要确认的工具调用时，TUI 会在输入框上方提示栏的外框内显示审批提示——这个外框同时容纳待办列表与中途更新。输入框保持挂载，已输入的内容不会丢失，但提交会被暂缓到请求处理完毕。提示默认折叠为紧凑摘要，仍会显示编号选项（每个选项独占一行），因此无需展开即可用 `1` / `2` / `3` 或 `Enter` 作答；`Ctrl-T` 可展开详情。详细审批流程见[交互与输入](../guides/interaction.md#审批流程)，可用键位如下：

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 在候选选项之间移动光标 |
| `Enter` | 确认当前选中的选项 |
| `1` ~ `9` | 直接选择对应序号的选项 |
| `Esc` / `Ctrl-C` / `Ctrl-D` | 拒绝当前请求 |
| `Ctrl-E` | 提示内包含 diff 或文件内容预览时，用全屏查看器打开完整内容 |
| `Ctrl-O` | 切换其他工具输出的折叠状态 |

需要附带反馈的选项（如「Reject」「Revise」）会在确认后切换到反馈输入态：直接输入反馈文本，按 `Enter` 提交；按 `Esc` 退出反馈输入并回到候选列表。

## 弹窗模式

输入 `/help` 打开帮助面板后，可使用以下键位浏览和关闭面板：

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 单行滚动 |
| `PageUp` / `PageDown` | 每次滚动 10 行 |
| `Esc` / `Enter` / `q` / `Q` | 关闭面板 |
