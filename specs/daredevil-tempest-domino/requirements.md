# Requirements — 自训练关联记忆（associative memory）

## 目标

给 agent 一个**会随使用自我演化**的记忆子系统：经验被编码成离散的记忆单元，单元之间靠共现学习出连接、随时间衰减，线索到来时沿连接扩散激活、自动召回相关旧经验。它**不依赖**现有的 markdown 文件记忆，是一个与它并存的新子系统。

这套系统要解决的是现有记忆方案（整篇 markdown + 全文检索）做不到的一件事：**被动联想召回**——不需要模型知道该查什么、也不需要用对词，每轮根据当前线索自动把相关旧经验推过来。

## 受众

- **开发者**：维护 `packages/agent-core-v2` 的 feature / DI / reminder / tool 体系的工程师。
- **使用者**：跨会话长期工作、经验量超出上下文窗口、需要"被动联想召回"的 agent 用户。

## 核心纪律（贯穿全文）

> **法典是记忆的目标函数。**
> 写入、召回、连接强化、冲突裁决、遗忘，全部受法典约束。法典由**硬规则**（结构化、确定性执行）与**软指引**（自然语言、注入系统提示、模型参照判断）组成。Hebbian 训练只强化不违反法典的连接。

这条纪律来自一个判断：没有目标信号的纯 Hebbian 共现学习，只能学到"什么和什么一起出现过"，学不到"什么有用、什么不该出现"。法典补上的正是这一层——它是"训练"的方向。

## 核心概念

| 概念 | 含义 |
| --- | --- |
| **原子单元 atom** | 一段自洽的经验陈述（短文本 + 词项 + 向量）。由模型写入的原始笔记切分而来，是"tokenizer"的输出 |
| **概念 concept** | 一组高频共现原子的簇，带概括标签。概念本身也是图节点，能连边、被激活、被召回 |
| **连接 edge** | 带权有向边，权重 = 关联强度，随使用强化、随时间衰减 |
| **法典 code** | 硬规则 + 软指引。管写入过滤、召回过滤、冲突裁决、保留/遗忘、训练约束 |
| **扩散激活 recall** | 线索 → 初始激活 → 沿连接传播（衰减）→ top-k 收敛 |
| **训练 training** | 写入即训练：新原子与"被它唤起的旧原子"建立/强化连接 |

## 需求

### R1 — 编码（写入即训练）

- 模型通过工具写入一条原始笔记（自然语言）。
- 编码器把笔记切成 1..n 个原子单元（按段落 / 标题 / 句子，有字数上限）。
- 切分是**确定性**的：纯函数，无模型调用、无随机。
- 每个原子计算：词项（复用 minidb 分词器）、本地稀疏向量（TF-IDF，余弦）。
- 写入前过**法典写入闸门**（R5）：违反硬规则的笔记不入库、不训练；软指引由模型在工具描述 + 系统提示的约束下自判。

### R2 — 概念层（在线共现聚类）

- 维护原子间的共现计数（一起被写入 / 一起被激活的次数）。
- 共现强度超阈值、簇大小在 [min, max] 之间时，**确定性**地提升为概念单元，与簇内原子连边。
- 聚类无随机性：固定参数、固定 tie-break（按 id 排序），可复现。
- 概念标签取簇内代表文本（确定性选取，如最高频词项所在的短句）。

### R3 — 衰减与剪枝

- 连接权重随时间**两段衰减**（近期幂律/对数、远期指数；按 `lastUsedAt` 惰性计算）。
- 被召回命中的连接：权重 += 强化量，`lastUsedAt` 重置为当前时间。
- 权重低于剪枝阈值的连接被删除，控制图规模。
- 被法典"钉住"（pinned）的记忆不参与衰减。

### R4 — 召回（一次性扩散激活）

- 线索（cue）分词后：
  1. **初始激活**：命中词项 posting 的原子/概念；本地向量相似度高于阈值的原子/概念。
  2. **扩散**：沿连接传播，权重按跳数衰减（如 ×0.5/跳），2–3 跳；原子层与概念层都参与。
  3. **收敛**：得到每个节点的激活值。
  4. **截断**：取 top-k（默认 8），低于激活阈值的剪掉。
- 召回前/后过**法典召回闸门**（R5）。
- 矛盾记忆按法典的冲突裁决规则处理（R5），并在结果中标注冲突。

### R5 — 法典（code）

- **来源**：内置默认（代码常量）+ 用户可写（一个用户文件）+ 模型提议（经用户批准写入用户文件）。
- **硬规则**：结构化（模式 + 动作 + 理由），确定性执行。作用于：写入过滤、召回过滤、冲突裁决、保留/遗忘、训练约束、embeddings 外发门禁。
- **软指引**：自然语言原则，注入系统提示（类似 `${behavior_contract}`），模型在写入/召回时参照判断；判断结果写入审计日志。
- **冲突裁决优先级**（默认，用户可改）：用户明确声明的 > 推断的；更新的 > 更旧的。该规则只用于**标注与排序**，不代替模型决策——冲突的多个原子一起返回，各带溯源（见 R4）。
- 内置默认至少包含：凭据/密钥类内容不入库；用户明确要求删除的彻底清除。
- **再巩固**：`reconsolidate` 把新证据显式写回被召回的记忆；矛盾则覆盖旧记忆（保留溯源）。

### R6 — 自动注入（reminder）

- 注册一个新的 reminder 变体，每轮新对话时触发，线索取"上一条用户消息"（与 gitMemory 的 `git_memory_signal` 同源）。
- 召回到 top-k 后渲染成一个块，包成 system reminder 注入上下文，不污染用户消息。
- 注入块有 token 预算上限；超预算时按激活值截断。
- 与 gitMemory 的记忆注入去重（共享已渲染集合，避免同一条经验注入两次）。

### R7 — 显式工具

- 新工具 `MemoryGraph`，actions：`write` / `recall` / `pin` / `forget` / `list` / `export` / `replay` / `propose` / `approve` / `label` / `reconsolidate` / `audit` / `stats` / `explain` / `rebuild`。
- 工具描述引导模型"学到值得记住的东西时写"，不自动、不强制。
- 工具受法典约束（写入时）。

### R8 — 隔离与存储

- **三维 scope**：`project`（每个项目一个独立实例，写入默认）/ `global`（跨项目）/ `all`（读取默认，同时查两者）。
- 存储使用 MiniDb（增量写、WAL），不重写整文件。
- 索引/数据损坏时可从笔记重建（`rebuild`）。

### R9 — 可观测

- `stats`：原子/概念/程序/边/笔记数量与钉住/抑制统计。
- `explain`：一次召回的 Recall Trace（种子、扩散、抑制、截断），用于 debug"该想起的没想起来"。
- `audit`：JSONL 审计日志，记录写入过滤、召回过滤、pin/forget、supersede、embeddings 决策、replay、rebuild、提议/批准、标签；`audit` action 查看，`export` 内含。
- `list` / `export` / `rebuild`：列出内容、导出、从笔记重建。
- 离线评测基准（`eval.bench.ts`）：合成语料 + 真实 service，输出 hit@1/hit@5/MRR。

### R10 — 测试与可复现

- 编码器、Hebbian 更新、衰减、聚类、激活、渲染全部为可单测的纯函数。
- 时间依赖通过注入时钟测试，保证可复现。
- 集成测试：写一条笔记 → 召回能命中；违反硬规则的笔记不入库。

## 边界（明确不做）

- **替换现有 markdown 记忆**：新系统与现有 `app/memory` 并存，互不干扰。
- **后台自动再巩固**：再巩固由工具 action 显式触发（模型读到召回结果后写回），不做成后台自动写回——后者无法判断"是否真的矛盾"。

## 已识别的问题与对策（摘要）

设计过程中识别的主要风险与对应机制，完整讨论见设计文档：

| 问题 | 对策 |
| --- | --- |
| 训练无目标信号 | 法典层（R5）：Hebbian 只强化不违反法典的连接 |
| 噪声 / 低质量写入 | 法典写入过滤 + 原子去重合并（R1/R5） |
| 矛盾记忆无解 | 法典冲突裁决 + 溯源字段 + 冲突标注（R4/R5） |
| 衰减抹掉重要知识 | 法典可钉住记忆，钉住的不衰减（R3/R5） |
| 概念聚类不稳定 | 确定性聚类 + 固定参数（R2） |
| 联想过度 / 不足 | 激活阈值 + top-k + 向量相似门槛（R4） |
| 上下文成本 | top-k + 注入块 token 预算（R6） |
| 与 gitMemory 重复 | 命名空间隔离 + 共享去重（R6） |
| 外部向量隐私 | 默认本地向量，外部显式 opt-in（边界） |
| 规模无界增长 | 容量上限 + 剪枝（R3） |
| 并发写 | 项目内串行化写锁（R8） |
| 可观测 / 可评估 | 最小调试接口 + 审计日志（R9） |
